# Contributing to CodeMentor AI

Thank you for considering a contribution.

## Before you start

- Search existing issues to avoid duplicating work.
- For a major change, open an issue first to discuss the proposed approach.
- Never include API keys, passwords, private student data, or confidential code in issues, tests, screenshots, or pull requests.

## Development setup

1. Create and activate a Python 3.10+ virtual environment.
2. Install dependencies with `pip install -r requirements-dev.txt`.
3. Run tests with `python -m pytest`.
4. For UI testing, configure a local `.env` file with your own API key. Do not commit it.

## Pull requests

- Keep each change focused.
- Explain the problem and the behaviour that changed.
- Add or update tests where practical.
- Update the README if setup, features, limitations, or usage changes.
- Do not claim a feature is complete unless it works and has been checked.

## Reporting a bug

Include the steps to reproduce, expected behaviour, actual behaviour, and relevant error messages. Remove API keys and other secrets from logs before sharing them.
